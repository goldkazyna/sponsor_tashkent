# Профили/анкеты — переход на обычный сайт знакомств

**Дата:** 2026-06-16
**Статус:** утверждён, реализуется

## Цель

Уйти от «объявлений спонсоров» к обычному сайту знакомств: пользователи заполняют
анкету (профиль) в личном кабинете (вход по текущим email+паролю), анкеты сразу
показываются на главной сеткой карточек.

## Таблица `profiles`

| поле | тип | назначение |
|---|---|---|
| `id` | INT PK AUTO_INCREMENT | |
| `user_id` | INT, UNIQUE | одна анкета на пользователя (связь с `users.id`) |
| `name` | VARCHAR(100) NOT NULL | имя анкеты |
| `birthdate` | DATE NOT NULL | дата рождения (возраст вычисляем; обязательно) |
| `city_id` | INT NOT NULL | ссылка на `city.id` |
| `photo` | VARCHAR(255) NULL | путь к фото (WebP) |
| `about` | TEXT NULL | о себе |
| `created_at`, `updated_at` | TIMESTAMP NULL | |

- Пол НЕ дублируем — берём из `users.sex` (1=мужчина, 2=женщина) через join.
- Возраст вычисляем из `birthdate` (Carbon), показываем всем.

## Создание таблицы

- **Локалка/тест:** Laravel-миграция `create_profiles_table`.
- **Прод (нет CLI):** секретный роут `/create-profiles-table-secret` —
  `CREATE TABLE IF NOT EXISTS profiles (...)` (идемпотентно). Закрыть в robots.txt.

## Личный кабинет («Моя анкета»)

- Вход — текущие email+пароль (уже реализовано, `session('user_id')`).
- Страница в группе `/profile/*`: форма
  - имя (text, required),
  - дата рождения (date, required),
  - город (select из `city`),
  - фото (file, конверт в WebP через Intervention/Image, как у объявлений;
    папка `public/uploads/profiles/{user_id}/`),
  - о себе (textarea).
- Сохранение — upsert в `profiles` по `user_id`. Анкета сразу видна на главной.

## Главная

- `PostController::index()` (или новый метод) тянет анкеты:
  `profiles` JOIN `users` (sex) JOIN `city` (title), сортировка по свежести.
- Карточка: фото (или аватар по полу, или «зарегистрируйтесь» для гостей с фото),
  имя + возраст (из birthdate), город. Логика аватара/замка — уже готова.
- Фильтр «Кого ищу» → по `users.sex`; город → по `profiles.city_id`.
- Тестовые данные заменяются реальным запросом.

## Этапы

1. Таблица (миграция + секретный роут).
2. Форма анкеты в кабинете (+ загрузка фото в WebP).
3. Вывод реальных анкет на главной (замена тестовых данных, фильтры).

## Прод-заметки

- `ANTHROPIC_API_KEY` и пр. — не относится. Нужны права на запись в
  `public/uploads/profiles/`.
- После деплоя: открыть `/create-profiles-table-secret` один раз, затем `/clear-cache-secret`.
